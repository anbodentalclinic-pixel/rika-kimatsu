# 理科 期末テスト（中1 定期テスト③）

光・音・力・植物の分類・動物の分類の5単元を、1つにまとめた学習アプリです。
最初の画面（理科メニュー）から単元を選びます。各単元の進み具合と、まちがえた問題の数がメニューに出ます。

| 単元 | 範囲 | 紙でやるところ |
|---|---|---|
| 光（エネルギー1章） | 教科書 p.200〜221 | ワーク p.90〜99 |
| 音（エネルギー2章） | 教科書 p.222〜231 | ワーク p.100〜103 |
| 力（エネルギー3章） | 教科書 p.232〜235 | ワーク p.104 |
| 植物の分類（生命1章） | 教科書 p.31〜35 | ワーク p.7 |
| 動物の分類（生命2章） | 教科書 p.36〜53 | ワーク p.10〜13 |

- 光・音・動物：ステージ攻略（体験 → 見てさわる → いい例・悪い例 → 問題 → ボス）。まちがえた問題はカラスが持っていき、あとでもう一度出ます。右上の「保護者」でお試しモード（全ステージ開放・記録なし）。
- 力・植物：体験 → 理解 → 問題 → 紙。まちがえた問題は「まちがい直し」にたまります。
- 記録は使っている端末のブラウザの中だけに保存されます。どこにも送信しません。
- 学校のワークの問題そのものは入れていません。同じ型の問題を作り直しています。

## 公開方法（GitHub Pages）
1. GitHub で新しいリポジトリを作る
2. `index.html`・`icon.png`・`.nojekyll`・`README.md` をアップロード
3. Settings → Pages → Branch を `main` / `(root)` にして Save

※ 以前の「音による現象」「動物のなかま分け」を同じGitHubアカウントのPagesで公開していた場合、同じブラウザで開けば、それまでの記録（クリア・カラス）をそのまま引きつぎます。

## 今日の直し
理科メニューのいちばん上に、全単元のまちがいを、つまずきが多い順にまとめて出します。「説明を見直す」でそのステージの体験・説明から、「直す」でそのまちがいだけを解き直せます（全問正解するとリストから消えます）。

## テスト前の苦手復習
今までに1回でもまちがえた問題を「苦手」として記録し続けます（直したあとも消えません）。理科メニューの「テスト前の苦手復習」から、単元ごとに苦手な順で最大20問を解き直せます。苦手復習で正解すると「克服」に近づき、まちがえると「今日の直し」に入ります。

## 進み具合をGoogleスプレッドシートで見る
理科メニューの下「記録の送り先（保護者用）」に、スプレッドシート「拓真 理科記録」の Apps Script ウェブアプリのURLを設定すると、進み具合（まとめ・日報・まちがい・単元ごと）がスプレッドシートに届きます。設定手順はスプレッドシートの「設定方法」シートにあります。
